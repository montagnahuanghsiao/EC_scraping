# 購物網爬蟲 (Product Scraper)

這是一個基於 Python Selenium 開發的自動化爬蟲工具，專門用於抓取購物網的商品資訊。

## 🌟 功能特點
- 支持多頁面自動翻頁抓取
- 自動下載並分類商品圖片
- 將抓取的商品資料存儲為 CSV 格式
- 內建 ChromeDriver 自動管理機制

## 🛠️ 安裝步驟
